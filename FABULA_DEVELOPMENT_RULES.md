# FABULA DEVELOPMENT RULES

## Filosofia
Fabula è un editor narrativo professionale. Ogni modifica deve privilegiare semplicità, stabilità, leggibilità ed estendibilità.

## Workflow obbligatorio
1. Analizza la richiesta.
2. Indica file da modificare e possibili rischi.
3. Attendi la mia conferma.
4. Implementa la modifica.
5. Verifica che non vi siano errori JavaScript, HTML o CSS.
6. Riassumi cosa hai modificato.

## Regole di sviluppo
- Una modifica = un solo obiettivo.
- Modifica il minor numero possibile di file.
- Non modificare codice non richiesto.
- Non duplicare funzioni.
- Non riscrivere interi file se bastano poche righe.
- Mantieni la retrocompatibilità del progetto.

## Codice
- Preferisci soluzioni semplici e facilmente manutenibili.
- Evita hack, workaround e tecniche avanzate se non indispensabili.
- Scrivi codice modulare, leggibile e riutilizzabile.
- Usa nomi descrittivi e commenti solo quando utili.

## UI
- Mantieni uno stile minimalista e coerente.
- Nessun bordo superfluo.
- Input con sola linea inferiore.
- Evita effetti grafici inutili.
- Ogni nuovo componente deve rispettare il design esistente.

## Prima di concludere
Controlla sempre che:
- non ci siano errori in Console;
- non siano state introdotte regressioni;
- la modifica rispetti queste regole.

La stabilità del progetto ha sempre la priorità rispetto alla velocità di sviluppo.
